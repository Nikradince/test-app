# Решение

## Сколько заняло

Около 10 минут работы агента: копирование репозитория, реализация и проверки.

## Что сделано и что не успел

Готовы загрузка по HTTP, карточки матчей, русские статусы, местное время, фильтры, избранное, обновление, загрузочный индикатор, ошибки с повтором и пустой экран. Исправлены обе жалобы; дополнительно выбраны тесты логики фильтра и пограничных данных — без новых зависимостей.

Проверено: `npm test` (7 тестов), `npm run typecheck`, `npx expo export --platform web`. Агент также проверил приложение в браузере: реальные данные, 0:0, московское время, переключение фильтров, добавление/удаление избранного, рост и сброс таймера, ширина 375 px; с подменёнными HTTP-ответами — 503, повтор, пустой массив и неверный формат данных. На физическом телефоне не проверялось.

## Решения

- «Предстоящие» включает scheduled и postponed: перенесённый матч ещё не завершён. live показан только во «Все», поскольку он уже начался; finished — в «Завершённые». Незнакомый статус остаётся во «Все» с подписью «Статус неизвестен».
- Фильтры опираются на статус сервера, а не на текущую дату: в примере есть scheduled с прошедшей датой. Даты переводятся через `toLocaleString` без фиксированного часового пояса; null или некорректная дата показываются как «Дата уточняется».
- Счёт проверяется на null, поэтому 0:0 не теряется. Стабильный ключ карточки — id матча. JSON проверяется на границе сети, включая уникальность id; ошибка формата видна пользователю.
- В исходном MATCHES_URL оставался OWNER/REPO: заменён на адрес data/matches.json в публичном fork. При ошибке обновления сохраняются предыдущие данные и момент последней успешной загрузки. Запрос отменяется при размонтировании; таймаут — 15 секунд.

## Баги из части 2

1. Звёздочки: `indexOf` возвращает -1 для отсутствующего id (это true после Boolean), а для первого элемента — 0 (false); заменено на `includes`. Кроме того, push/splice меняли тот же массив, и React мог пропустить перерисовку: теперь функциональное обновление создаёт новый массив на основе актуального состояния.
2. «Обновлено N сек назад»: интервал замыкал начальное seconds=0 и каждый раз устанавливал 1; since не использовался, интервал не очищался. Теперь время считается как разница Date.now() и since, эффект зависит от timestamp и очищает интервал; новый успешный ответ сбрасывает отсчёт, а задержки вкладки не накапливают погрешность.

## Как я использовал ИИ

Реализацию и проверки выполнил Codex; автор задания разрешает такой формат. Агент прочитал исходники и документацию Expo SDK 57, затем запустил typecheck, тесты, web-сборку и браузерные сценарии. Личной проверки кандидатом на момент подготовки этого файла ещё не было; перед отправкой ему нужно пройтись по коду и воспроизвести сценарии.

Первоначальный запуск Expo в ограниченной среде не удался из-за доступа к каталогу телеметрии; локальную проверку запустили с EXPO_NO_TELEMETRY=1 и EXPO_OFFLINE=1. Тесты сначала использовали встроенное выполнение TypeScript новой версией Node, затем были исправлены: теперь исходник транспилируется уже имеющимся TypeScript и тесты не требуют этого нового режима Node.
